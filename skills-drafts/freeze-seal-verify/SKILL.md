# 凍結物の封印と改変検知

## 目的
「凍結」を宣言だけで終わらせず、ハッシュで照合可能な状態にし、別ブランチや後続コミットで凍結物が置き換わった事実を検出・報告する。

## 発動条件
- 「凍結」「FROZEN」「封印」「READ-ONLY」の宣言
- 凍結物を含むブランチを main 等へマージする前
- 凍結物と同じパスのファイルを編集・差し替えする指示を受けた
- 凍結済みフェーズの成果物について照会を受けた

## 入力
| 項目 | 内容 |
|---|---|
| 凍結対象 | パス一覧 |
| 封印コミット | 凍結時点のコミット（全長ハッシュ） |
| 比較対象ブランチ | 例: `main` |

## 出力
| 項目 | 内容 |
|---|---|
| マニフェスト | `sha256sum` 形式（`<64桁>  <path>`）、封印コミット、UTC日時 |
| 照合結果 | ファイルごとの一致 / 不一致 |
| ブランチ間乖離表 | パス / 封印ハッシュ / 比較ブランチ上のハッシュ / 比較ブランチ上の最終更新コミット |
| 報告 | 乖離の事実のみ（どちらを正とするかは記載しない） |

## 手順
1. 凍結対象を確定し、作業ツリーがクリーンであることを確認する（`git status --porcelain` が空）。
2. マニフェストを作成する。
   ```bash
   sha256sum <path1> <path2> ... > FREEZE_MANIFEST.sha256
   git rev-parse HEAD   # 封印コミット（全長）
   date -u +%Y-%m-%dT%H:%M:%SZ
   ```
3. マニフェストを凍結宣言文書と同時にコミットする。ハッシュは全長64桁で記録する。
4. 照合（随時・マージ前）。
   ```bash
   sha256sum -c FREEZE_MANIFEST.sha256
   # 過去の封印コミット時点の内容を照合する場合
   git show <封印コミット>:<path> | sha256sum
   ```
5. ブランチ間乖離の確認。
   ```bash
   git show main:<path> | sha256sum
   git log -1 --format='%h %ad %s' --date=iso main -- <path>
   git branch -r --contains <封印コミット>   # 封印コミットがどのブランチに含まれるか
   ```
6. 不一致・乖離を報告する。解消方法（マージ・revert・新版化）は利用者が決める。
7. 凍結物に変更が必要な場合は、凍結物を編集せず `app-variant-lineage-registry` で新版を作る。
8. 監査ログ（PASS/FAIL）を残す場合は、実行したコマンドと出力を併記する。

## 注意点（やってはいけないこと）
- 凍結物を1文字も編集しない（整形・改行コード変更を含む）。
- 照合を合わせる目的でマニフェストを事後に書き換えない。
- ハッシュを先頭8桁等に切り詰めて記録しない（照合根拠が弱くなる）。
- 乖離を自己判断で解消しない（main の上書き・revert・強制 push をしない）。
- コマンドと出力を伴わない「PASS」記録を作らない。
- 凍結が別ブランチ上だけで宣言されている場合、main 側が保護されていないことを報告から省かない。
