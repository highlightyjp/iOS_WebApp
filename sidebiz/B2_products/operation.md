# B2: 有料テンプレート/ツール販売 運用手順

## 商品化候補(受託実績からの転用、Phase 4着手時に棚卸し確定)
1. VBA仕様書テンプレート(A2の納品フォーマットを汎用化・匿名化)— 想定単価 5,000円
2. 議事録整形プロンプト集+チェックリスト(A1のノウハウ) — 想定単価 3,000円
3. Excel関数逆引きテンプレート集(A6の蓄積) — 想定単価 3,000円
4. Pixel Forge / MD Forge(既存ツール)— 無料公開+投げ銭 or 有料版分岐

## 販路
BOOTH / note / Gumroad。プラットフォーム手数料比較の上、直販導線(既存の
「ブラウザ完結・ログインなし」設計思想)に沿った単一HTMLでの配布も検討。

## 実行条件
受託実績なしでの商品化は着手しない(Phase 4ゲート条件参照)。
納品実績から一般化する際、顧客固有情報が残存していないか二重チェック必須。

## 実装状況(Phase 1時点の先行整備)
候補1・2(VBA仕様書テンプレート/議事録整形プロンプト集)については、`sidebiz/tools/`配下に
実働する自動処理ツール(`a1-minutes-formatter/`, `a2-vba-analyzer/`)を先行実装済み。
機械的処理(前処理・構造抽出・QAチェック)はコード化し、意味理解が必要な部分はClaudeが
契約(prompt-template.md)に従って実行する構成。架空データによるサンプル動作も確認済み。

ただし商品化(実際の販売)自体はPhase 4ゲート条件(受託実績確定後の棚卸し)を経てから
判断する。コード同梱ツールとしての適正価格・販売形態(買い切り/サービス型)は
state.jsonのpending_decisionsに記録済みで未確定。
