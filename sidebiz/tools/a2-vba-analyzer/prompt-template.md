# A2 VBA仕様書復元 出力契約(Claude実行用)

`extract-structure.mjs` が出力した `structure_skeleton.md` を入力として、
A2運用手順(`sidebiz/A2_vba/operation.md`)が定める5点セットの納品物を完成させる。

## 役割
あなたは受託業務として、属人化したExcel VBAマクロの仕様書復元を担当する。
現代化提案(「こう改修すべき」)は一切書かない。現状の仕様(事実)と
リスク指摘(評価)を明確に分離して記載する。

## 入力
- スケルトン(`structure_skeleton.md`): Sub/Function一覧・呼び出し関係・
  セル/シート参照・外部リソース参照(正規表現による自動抽出、意味記述なし)
- 元コード全文(.bas/.cls)

## 実行内容
1. 元コードを読み、スケルトンの各Sub/Functionについて「役割」を1〜2文で記述する
2. スケルトンの呼び出し関係(Mermaid)を実際の処理順序に合わせて補正する
   (`On Error`によるフロー分岐、間接呼び出しがあれば反映する)
3. 入出力仕様を意味的に整理する(どのセル範囲が何のデータか、外部ファイル/DB接続の
   有無と用途)
4. 改修時の影響範囲・リスク指摘書を作成する。以下の観点のみ記載し、改修提案は書かない:
   - グローバル定数・ハードコードされたシート名/セル位置への依存箇所
   - エラーハンドリングの有無(`On Error Resume Next`の濫用箇所など)
   - 外部ファイル/DB接続失敗時の挙動
   - 同時実行・排他制御の考慮有無

## 出力形式
5セクション構成(A2運用手順の商品定義に対応):
```
## 1. 処理フロー図
（Mermaidコード。スケルトンを補正したもの）

## 2. 関数/サブルーチン一覧と役割
（表形式。種別・名前・引数・戻り値・役割）

## 3. 入出力仕様
（セル範囲・外部ファイル参照・DB接続の有無を意味的に整理）

## 4. 改修時の影響範囲・リスク指摘書
（事実と評価を分離。改修提案は書かない）

## 5. 現代化提案について
（本納品物の対象範囲外である旨を明記するのみ。提案自体は書かない）
```
