# A2 VBA仕様書復元ツール(vba-analyzer)

v0.1.0 — 社内利用中。B2フェーズでの外部販売を想定した汎用パッケージ構成。

## 何をするツールか
属人化したExcel VBAマクロを解析し、A2運用手順(`sidebiz/A2_vba/operation.md`)が定める
5点セット(処理フロー図/関数一覧と役割/入出力仕様/リスク指摘書/現代化提案なしの明記)の
納品物作成を支援する。

- **決定的に処理する部分(コード)**: 正規表現によるSub/Function抽出、呼び出し関係の
  ベストエフォート抽出、Range/Cells参照・シート参照・外部リソース参照の抽出
- **意味理解が必要な部分(Claude)**: 各関数の役割記述、処理フローの補正、
  入出力仕様の意味的整理、リスク評価

## 使い方
```
node extract-structure.mjs <macro.bas> --out=output
# → output/structure_skeleton.md が生成される(役割・リスク評価は空欄)
# Claude Codeセッションでこのファイルと元コードを読み、
# prompt-template.md の契約に従って納品レポートを完成させる
```
本ツールにAPIモードは実装していない(VBAコードの意味解析はコンテキストが大きく
1回のAPI呼び出しで完結させにくいため、Claude Codeセッションでの対話的な確認を前提とする)。

## サンプル(架空データ・Phase 1→2ゲート対応)
- `sample-input/inventory_macro_sample.bas`:架空の在庫管理・自動発注マクロ(約300行)
- `sample-output/structure_skeleton.md`:自動抽出のみのスケルトン
- `sample-output/spec_report_sample.md`:Claudeが意味記述を追記した納品サンプル一式

このサンプルは`phase_gates.md`の「VBA解析サンプル納品物1件自作完了(架空マクロで実施)」
に対応する成果物であり、出品ページのポートフォリオ添付候補。

## 既知の制約
- シート名を`Sheets("商品マスタ")`のようにリテラル文字列で参照している箇所のみ検出可能。
  本サンプルのように`Const`定数経由の参照は検出できない(サンプル実行結果で実証済み・
  `structure_skeleton.md`のシート参照が「検出なし」になっている理由)
- 呼び出し関係の抽出は単純な名前一致によるベストエフォートであり、間接呼び出し
  (Application.Run等)・Property経由の呼び出しは検出できない
- パスワード保護されたVBAプロジェクトの解除は行わない(A2運用手順の注意事項準拠。
  本ツールはあくまで平文で読めるコードを前提とする)
