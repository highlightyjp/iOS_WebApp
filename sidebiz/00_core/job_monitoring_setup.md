# 案件モニタリング体制(A1/A2共通)

## 目的
A1(議事録整形)・A2(VBA仕様書復元)に合致する募集中案件を、継続的な手動検索なしで
把握できるようにする。

## 調査結果:非採用とした手段
- **クラウドワークスへの非ブラウザ(スクレイピング)アクセス**:サイト側が拒否しており
  取得不可。User-Agent偽装等での回避は利用規約(自動アクセス禁止)への抵触リスクが
  あるため不採用と確定
- **ランサーズの検索結果ページのスクレイピング**:検索エンジン経由でヒットする一覧には
  募集終了済み案件が多数混在し、「募集中のみ」フィルタはログインセッション/JS操作が
  前提。非ログイン状態での機械的取得は信頼できず、ログインセッションを使った自動化も
  同様に利用規約上のリスクを伴うため不採用
- **公開API/RSSフィード**:両社とも外部開発者向けには提供されていない(2026-07-07時点で
  確認。クラウドワークスの内部APIは自社アプリ専用)

## 採用した仕組み:公式通知機能(規約準拠・ユーザーの継続操作不要)

### クラウドワークス:検索条件保存(公式アプリ)
1. 公式スマホアプリにログイン
2. お仕事検索でキーワード(例:「議事録作成」「VBA」「マクロ」「Excel VBA」)を入力し検索
3. 検索結果画面から「検索条件を保存」を実行
4. 以降、保存条件に該当する新着案件が1日1回(正午頃)プッシュ通知される
5. 通知は「保存条件」タブから一覧確認・応募可能

### ランサーズ:新着仕事通知メール
1. マイページの通知設定を開く
2. 興味のあるカテゴリ(「システム開発」内のVBA関連、「テープ起こし・文字起こし・書き起こし」等)
   を登録
3. 該当カテゴリに新着案件が掲載されるとメール通知が届く
4. キーワード単位の通知には対応していない(2026-07-07時点、カテゴリ単位のみ)ため、
   通知メールの中からA1/A2に合致するものを都度判断する必要がある

## 制約・注意事項
- 上記設定はユーザー本人のアカウントでの初回設定が必要(ログイン情報を要するため
  エージェントが代行しない。CLAUDE.mdの人間承認必須事項に準ずる)
- 通知を受けた案件への実際の応募は引き続き人間承認必須事項
- ランサーズはキーワード単位の絞り込みができないため、カテゴリ通知の中からA1/A2の
  条件に合うものを人力で選別する一手間が残る。これは仕様上の制約であり解消手段なし
