社内Copilotへ渡すパッケージです。渡し物は1ファイル（qb-package.txt）にまとめてあります。中身の切り分けと照合は Copilot 側が行います。添付は .txt のまま（.js や .json の添付は入口で止められやすいため）。

■ パッケージ（1ファイル）

手順：このファイルを社用端末へ運ぶ（「パッケージを送る」か「ダウンロード」）→ Copilot（Cowork）で Work IQ をオンにする → チャットに添付する（または OneDrive に置いて / で参照する）→ 下の「短い指示文」を貼って送る → Copilot が照合結果を返したら「生成して」と送る。OneDrive に置いておけば、次回からは参照と短い指示文だけで済みます。

■ PDF等のファイルから送る場合

QRで運ぶのは常にテキストです。PDF等のファイルは、先に Copilot（Cowork）へ添付して構造化テキストに変換し、そのテキストを送り側ツールへ貼ってQR化します（ファイル自体は運びません）。変換には下の指示文を使ってください。構造化テキストが長くて1枚に収まらない場合は、段落単位で分けて複数回に分けて送ります。
